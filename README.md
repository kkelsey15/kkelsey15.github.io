# 熊萱逸｜科研个人主页（深蓝简约版）

本版本已彻底删除 Gallery / 图集页面与对应导航。

## 文件
- index.html：首页
- research.html：科研经历
- projects.html：项目与技能
- assets/style.css：深蓝白色高级简约风
- assets/i18n.js：中文/英文切换
- assets/main.js：交互入口
- assets/images/portrait.jpg：个人照片位置

## 上传你的照片
将自己的照片命名为 `portrait.jpg`，上传并替换 `assets/images/portrait.jpg` 即可，不需要修改 HTML。

## GitHub Pages
将这些文件上传到仓库根目录，确保 `index.html` 在最外层。
